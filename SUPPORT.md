# Support

- Ask usage questions in [GitHub Discussions](https://github.com/rohanpoudel2/qrs/discussions).
- Report reproducible defects using the bug issue form.
- Propose scoped product changes using the feature request form.
- Report vulnerabilities privately as described in [SECURITY.md](./SECURITY.md).

This is a community-maintained pre-release project. Support is best-effort and has no guaranteed
response time.
